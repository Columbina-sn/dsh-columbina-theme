# 背景图请自备 / Bring your own background

这个目录在仓库里是空的：**本项目不附带任何背景图**，避免把角色美术、同人图或你本机的私用图一并分发。

## 怎么用

把图片直接放进本目录：

- 支持：`png` / `jpg` / `jpeg` / `gif` / `webp` / `avif`
- 单张上限：24 MB
- 推荐尺寸：**2560×1440 或更大，16:9**
- 文件名只用于排序和显示，不会被执行；按文件名排序，第一张是默认起点。

插件用 CSS `background-size: cover` 自动铺满窗口，所以不需要手动裁切成某个固定比例；横窗、竖窗都会按窗口裁切，不会留白。想换图/加图，刷新页面即可在「设置 → 哥伦比娅 · 主题」的缩略图条里看到。

没有图片时，主题会使用自带的月白 → 银蓝渐变底，人格、表情包、欢迎页都不受影响。

你放进去的图片请自行确认来源与授权；本项目不随仓库分发任何背景图。
